# SmithaGeorge.com

A responsive single-page professional profile website for Smitha George.

## Included
- Modern responsive design
- Professional hero/profile section
- Microsoft credentials
- SQL Server and Business Intelligence expertise
- Performance tuning, .NET and XML
- Microsoft India training experience
- Certification boot camps
- Techiya Solutions founder section
- Contact CTA
- Mobile navigation

## Customize before publishing
1. Replace the `SG` placeholder in the hero with Smitha's professional photograph if desired.
2. Change `hello@smithageorge.com` to the preferred contact email.
3. Add LinkedIn / social links if available.
4. Add the official Techiya Solutions website URL if one exists.
5. Update any dates, company names, certifications or biography details that need to match the official CV.

## Hosting
This is a static website and can be hosted directly on Nginx, Apache, IIS, GitHub Pages, Netlify, Vercel or similar hosting.
